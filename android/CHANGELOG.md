# Historial

## 0.3.0 · 2026-10-09

Añade Productos: importación privada offline de packs Atlas v1 con validación
antes de sustitución, selector de proyecto, historia mensual, indicadores, Model
Card, métricas de validación y escenario ajustable. La instalación del pack queda
separada de notas/progreso; no requiere red y puede eliminarse localmente. La
clave de firma de release no se encuentra en este entorno: APK y ZIP 0.3.0 aún
no compilados ni publicados. La verificación visual en teléfono queda pendiente.


## 0.2.0 · 2026-10-09

Reconstrucción Android independiente de 0.1.0. Añade intención de sesión,
preferencias, progreso con evidencia, respaldo JSON y atlas offline. Conserva
catálogo educativo, museo y ejemplo DiD a partir del repositorio web.

No incluye migración automática de datos desde 0.1.0 ni actualizaciones en vivo.
La implementación y distribución quedan versionadas para futuras mejoras.
